# C5 · 이론-실험 대응 (theory ↔ experiment correspondence)

**평가 목적.** 이론과 실험이 함께 있는 페이퍼라면, 이론에서 말한 것들이 실험에서 각각 대응되어 검증·설명되어야 한다.

### C5-Q01 · 이론에서 말한 각 주장이 실험에서 대응되어 검증·설명되는가? [active] [severity: high]
- why:   이론 주장이 실험으로 이어지지 않으면 그 주장은 미검증으로 남는다.
- check: 이론의 각 lemma·theorem·claim을 나열하고, 각각을 검증·예시하는 실험(figure/table)이 있는지 매핑. 대응 없는 이론 주장이 있으면 fail.
- applies_when: 페이퍼에 이론과 실험이 모두 있을 때.
- source: 사용자 지정 기준 (2026-07-26)

### C5-Q02 · 이론과 연결되지 않는 실험, 또는 실험으로 뒷받침되지 않는 이론 진술이 없는가? [active] [severity: med]
- why:   대응이 양방향으로 맞아야 서사가 닫힌다. 붕 뜬 실험이나 미검증 이론은 둘 다 약점이다.
- check: 각 실험이 어떤 이론 주장에 연결되는지, 반대로 각 이론 주장이 어떤 실험에 연결되는지 양방향 확인. 고아 실험·고아 이론이 있으면 partial 이하.
- applies_when: 페이퍼에 이론과 실험이 모두 있을 때.
- source: 사용자 지정 기준 (2026-07-26)
